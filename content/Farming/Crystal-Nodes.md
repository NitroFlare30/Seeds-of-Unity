# 💎 Crystal Nodes & Ecosystem Objects

Unlike Earth crops that only need watering and fertilizer, **Raea crops rely on ecosystem objects** to access the planet's native resources.

---

## Node Types

### Crystal Nodes
**Primary farming object**

| | |
|---|---|
| **Purpose** | Irrigate and channel Raea's mineral resources to crops |
| **Maintenance resource** | Minerals (from mining) |
| **Interaction** | Active — player must input resources manually |
| **Benefit** | Enhances crop growth alongside watering/fertilizer |
| **Himmie bonus** | Right Himmies present = nodes work more efficiently |
| **Failure state** | Degrade if unmaintained; crops suffer debuff |

---

### Pod Nodes
**Variety & discovery mechanic**

| | |
|---|---|
| **Purpose** | Produce random crops when mature |
| **Maintenance resource** | Foraged materials (gathered from exploration) |
| **Output** | Random crop selection — influenced by current season |
| **Benefit** | Introduces crop variety without explicit learning |
| **Tanilian benefit** | Provides varied food sources during learning phase |

---

## System Integrations

### Mining ↔ Farming
- [[Mining/index|Mine]] for minerals → maintain crystal nodes → unlock crystal crop access → thrive in Teal Season

### Foraging ↔ Farming
- Forage for materials → maintain pod nodes → pod nodes produce random crops (including root crops)

### Himmies ↔ Nodes
- Right Himmies present = nodes work more efficiently
- Wrong types / absence = nodes less effective
- Player learns Himmie preferences through observation — no tutorial
