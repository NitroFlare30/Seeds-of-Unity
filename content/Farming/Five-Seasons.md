# 🌟 Five Seasons

Raea orbits a **binary star system** — one smaller red star and one larger blue star. The planet's position relative to these stars creates five distinct seasonal phases instead of Earth's four.

**All crops can grow in any season**, but with penalties (slower growth, lower yield, visual degradation) for growing in the wrong season. **Exception:** Gray season — standard crops nearly impossible; only fungal crops thrive.

---

## Season 1: Teal Season
**Blue star dominant/rising**

| Aspect | Details |
|---|---|
| Sky | Bright blue/cyan |
| Light | Sharp, blue-tinted shadows; high intensity |
| Flora | Teal coloration (adapted to blue spectrum) |
| Radiation | High UV exposure |
| Feel | Clear, crystalline |
| **Best crops** | **Crystal crops thrive** |

---

## Season 2: Purple Descent
**Both stars visible; Blue fading, Red rising**

| Aspect | Details |
|---|---|
| Sky | Deep purple/violet (blue + red blending) |
| Light | Dual shadows, getting hazier; cooling |
| Flora | Purplish tint, starting to dull |
| Feel | Twilight-like, mysterious, dimming |
| Himmies | Show warning signs of the Gray season approaching |
| **Crops** | Transitional; prepare for Gray |

---

## Season 3: Gray / Bioluminescent Season
**Eclipse — both stars obscured or blocked**

| Aspect | Details |
|---|---|
| Sky | Gray, overcast; very low external light |
| Light | No direct star visibility; eerie |
| Flora | Bioluminescent flora glows; fungal growth dominates |
| Feel | Dark, alien, unique |
| **Best crops** | **Fungal crops ONLY** — standard crops heavily debuffed |
| Special | Bioluminescent crops produce their own light |

> The visual climax/pivot point of the seasonal cycle.

---

## Season 4: Violet Emergence
**Both stars visible; Red fading, Blue rising**

| Aspect | Details |
|---|---|
| Sky | Bright violet/magenta (red + blue rebalancing) |
| Light | Both stars visible; clarity improving; brightening |
| Flora | Iridescent/magenta tint, flora recovering |
| Feel | Dawn-like, awakening, hopeful |
| Himmies | Show relief/recovery as light returns |
| **Crops** | Bioluminescence fades, colors return |

---

## Season 5: Plum Season
**Red star dominant/rising**

| Aspect | Details |
|---|---|
| Sky | Deep plum/burgundy |
| Light | Long, soft red-tinted shadows; warm |
| Flora | Plum coloration (adapted to red spectrum) |
| Radiation | Warm infrared |
| Feel | Hazy, diffuse, warm |
| **Best crops** | **Flowering crops thrive** |

---

## Color Palette Summary

For 2D pixel art, flora shifts through this spectrum:

1. **Teal** — Bright, crystalline
2. **Purple** — Deep, mysterious
3. **Gray + Bioluminescent** — Eerie, glowing
4. **Violet** — Bright, awakening
5. **Plum** — Warm, diffuse

Crops and ecosystem shift visually with each season, communicating Raea's alien nature.
