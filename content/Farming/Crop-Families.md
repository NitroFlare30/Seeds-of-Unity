# 🌱 Crop Families & Progression

**~30 total crops by end-game** across five families. ~5–6 new crops per season.

> ⚠️ **OPEN:** this math assumed [[Five-Seasons|5 seasons]] (25-30 crops at 5-6/season). The season count was cut to **3** (Teal, Gray, Plum — see [[Five-Seasons]]). ## Five Crop Families

### 1. Root Crops
**Underground, hearty, soil-focused**

| | |
|---|---|
| **Unlock** | Foraging (seeds found in wild) |
| **Season** | All seasons viable |
| **Visual** | Earthy forms; shift with season palette |
| **Uses** | Food, possibly other resources |

---

### 2. Flowering Crops
**Colorful, seasonal, visually distinctive**

| | |
|---|---|
| **Unlock** | Quests, Himmie reveals, Pod node surprises |
| **Best season** | **Plum Season** |
| **Visual** | Alien blooms; vibrant when season-appropriate, muted otherwise |
| **Uses** | Food, aesthetic, possibly crafting |

---

### 3. [[Fungus-Crops|Fungal Crops]]
**Bioluminescent, eerie, stat-boosting**

| | |
|---|---|
| **Unlock** | **Gray Season exclusive** — only viable during Gray |
| **Best season** | **Gray Season ONLY** — impossible other seasons |
| **Visual** | Bioluminescent, glowing forms |
| **Uses** | Stat boosts (stamina, strength, speed, gem resonance) |
| **Rarity** | Scarce, seasonal unlock |

---

### 4. Crystal / Mineral Crops
**Crystalline structures, mineral-infused**

| | |
|---|---|
| **Unlock** | Mining (seeds/materials found underground) |
| **Best season** | **Teal Season** |
| **Visual** | Geometric, mineral-like, refractive; bright in Teal |
| **Uses** | Food, crafting materials, mining integration |

---

### 5. Vining / Climbing Crops
**Sprawling, grow differently, interconnected**

| | |
|---|---|
| **Unlock** | Quests, Himmie reveals, Pod node surprises |
| **Season** | All seasons viable |
| **Visual** | Organic networks; sprawling growth |
| **Uses** | Food, ground cover, ecosystem balance |

## Unlock Methods

| Method | Family | Notes |
|---|---|---|
| **Foraging** | Root crops | Seeds found in wild exploration |
| **Mining** | Crystal crops | Seeds/materials found underground |
| **Quests** | Flowering, Vining | NPCs/story unlock new crops |
| **Himmies** | Flowering, Vining | Observation reveals crop locations |
| **[[Crystal-Nodes\|Pod nodes]]** | All families | Random/surprising yields |
| **Gray Season** | Fungal crops | ONLY available during Gray Season |
| **Tanilians** | Any (2–4 max) | Minimal direct teaching — collaborative discovery |
