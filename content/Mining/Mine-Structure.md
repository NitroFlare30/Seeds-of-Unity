# 🪜 Mine Structure & Depth Tiers

## Structure

| | |
|---|---|
| **Layout** | Grid-based floors (tile grid per floor, not open 3D) — required for [[Resonant-Crystals\|resonant crystal]] radiation patterns to work |
| **Progression** | Depth-sequential — clearing a floor (finding the descent point) unlocks the next. No tool-tier or story gating layered on top |
| **Checkpoints** | Elevator every 5 floors — saves depth access, doubles as the [[Greed\|Greed]] "bank" point |
| **Generation** | Hybrid — standard floors regenerate procedurally each visit; every 5th floor (before each elevator) is a hand-authored "vault" floor with a deliberately designed resonant crystal cluster and a guaranteed better drop |

## Depth Tiers — Ore & Gem Distribution

| Floors | Tier | Introduces |
|---|---|---|
| 1–10 | Copper | Tile-breaking basics, Line crystal |
| 11–20 | Iron | X (diagonal) crystal |
| 21–30 | Silver | Plus (cardinal cross) crystal |
| 31–40 | Gold | Star crystal, full shape roster, denser clusters |
| 41+ | Gems | All 10 gem types, banded by rarity |

### Gem Rarity Bands (Floors 41+)

| Band | Gems |
|---|---|
| Common | Quartz, Citrine, Amethyst |
| Mid | Aquamarine, Kunzite, Topaz |
| Rare | Diamond, Ruby, Emerald, Sapphire |

**Optional thematic tie-in:** gem coloration could echo the [[Farming/Five-Seasons|five binary-star seasons]] (e.g., Aquamarine → Teal Season, Amethyst/Ruby → Plum Season). Not required, worth considering during the art pass.
